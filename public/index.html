Comment ça marche
1. Un joueur crée le salon.
2. Il partage le code aux autres.
3. Dès qu’il y a au moins 2 joueurs, l’hôte peut lancer.
4. À partir de 6 joueurs actifs, le jeu passe automatiquement à 2 paquets.
